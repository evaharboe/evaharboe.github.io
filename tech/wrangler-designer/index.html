Sony Europe · 2025 – 2026

Wrangler Designer

A visual, node-based editor for Sony's Java/XML Wrangler pipelines that took pipeline creation from hours to minutes.

ReactReactFlowZustandTypeScriptAWS

The problem. Building a Wrangler pipeline meant hand-writing Java/XML. It was slow, error-prone and only a few people could do it.

What I built. I started from a blank page and a vague idea, worked out with the team what would actually help, then led the design and build of a visual node-based editor. It uses ReactFlow for the canvas, Zustand for state, and AWS schema validation so invalid pipelines are caught before they run.

Impact. Pipeline creation went from hours to minutes. I set the feature direction, ran QA through JIRA and became the team’s go-to contact for the tool.
